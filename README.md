# Electrodeposición de níquel y cromo

Presentación de la práctica libre de Hidro y Electrometalurgia (UIS, noviembre 2026).

- `index.html`: versión web (usa la carpeta `assets/`). Flechas para navegar, tecla **P** para modo presentación.
- `Electrodeposicion_NiCr.html`: la misma presentación en un solo archivo, para usar sin internet.
- `Guion_Exposicion_NiCr.pdf`: guion técnico para los tres expositores.
- `src.html` + `assets/`: fuente editable. `python build.py` regenera el archivo único.
